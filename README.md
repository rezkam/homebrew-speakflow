# homebrew-speakflow

Homebrew tap for [SpeakFlow](https://github.com/rezkam/SpeakFlow) — voice-to-text dictation for macOS.

## Install

```sh
brew tap rezkam/speakflow
brew install --cask speakflow
```

## Update

```sh
brew upgrade --cask speakflow
```

## Uninstall

```sh
brew uninstall --cask speakflow
```
